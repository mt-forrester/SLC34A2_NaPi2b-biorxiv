# SLC34A2_NaPi2b-biorxiv

Code and results accompanying the bioRxiv preprint on NaPi2b (*SLC34A2*) as an alveolar
type 2 (AT2) cell surface marker.

- [`biorxiv/`](biorxiv/) — transcriptomic surfaceome screen of public human and mouse lung
  scRNA-seq data (see [`biorxiv/README.md`](biorxiv/README.md) to run it).
